# 教育訓練示範流程（D-02）

示範以無程式碼的網頁操作為主。每一段都有對應的 Playwright 腳本（`platform/web/e2e/demo-flow.spec.ts`），確保教材寫的步驟實際做得到（TC-D02-03：示範無法重現 0）。

| 段落 | 內容 | 狀態 |
|---|---|---|
| 1 | Admin 建立專案、指派成員與角色；成員登入後只看到有權限的入口 | 可示範，腳本通過（Chromium、Edge） |
| 2 | 上傳影像與 CSV、篩選、檢視統計 | 可示範，腳本通過（Chromium、Edge） |
| 3 | 影像標註、自動標註、修改後儲存 | 可示範，腳本通過（Chromium、Edge） |
| 4 | 建立訓練、匯出模型、部署與推論 | 可示範，腳本通過（Chromium、Edge）：從資料集「用這份資料建立訓練」、K 折交叉驗證、一句結論與圖表、報表、「分享給同事使用」與試用預測，從結果「用這個模型預測病人」（一位病人、多位病人與預測對錯） |

各段落從首頁開始、只點頁面上的連結與按鈕，彼此不依賴。

## 段落 2：上傳影像與 CSV、篩選、檢視統計

以 Research Assistant 登入。

1. 「數據管理」→ 選「醫療影像」：「匯入影像」上傳 DICOM，按「到研究列表查看」，以 Study Description 等條件篩選。
2. 上方分頁切到「結構式資料（CSV 表格）」（或在「數據管理」首頁直接選「結構式資料：上傳 CSV」）。
3. 按「選擇檔案」選 CSV 檔。平台自動判斷每一欄的型態，列在「欄位確認」表：整數、小數、類別、文字、日期、是否。每欄旁邊有缺值數、不同值數、範例與提示。
4. 依提示檢查：例如某欄「有 2 格空白」而這欄不該空白，就勾選「必填」；年齡、血壓等常見欄位已自動帶入合理範圍，可自行修改。按「重新預檢」看會有幾列被拒絕、原因是什麼。
5. 填資料集名稱，按「上傳並驗證」。不符合的列被拒絕並逐列列出原因，其餘的列進入資料集。名稱重複時可選「建立新版本」或「取代舊的」。
6. 按「開啟資料集」：先看到「描述統計」，各欄的平均、中位數與分布（0／1 欄位顯示為是／否與比例；平均、標準差等畫面上取到好讀的位數，滑鼠移上去看完整數值；P25、P75、標準差等表頭的說明預設展開）。每個分頁下方有一行說明它做什麼，例如「統計分析」是找出哪些因素和結果有關（迴歸、存活分析），和「描述統計」不同。「預覽」逐列看原始資料，列號從 1 起算；「相關與散佈圖」產生相關矩陣。
7. 「Target／Feature」：在欄位總覽表選「要預測的結果（Target）」（例如 diagnosis）與「用來預測的資料（Feature）」。表上會提示缺值多、像病歷號的識別碼、只有一種值的欄位。文字欄位（例如 sex）按「全部轉成 One-Hot」（把每個類別變成一個 0／1 欄位）；以數字代表分類的欄位（例如 0、1、2）打開「當作類別」。選到有缺值的 Feature（例如 glucose 有 5 位缺值）時，表下方會說出來，一鍵選「補上缺值」（數字補中位數、類別補最常見的值，建議）或「不使用這些病人」。按「儲存設定」，畫面寫出存了什麼，例如「用來預測的資料 7 個欄位（sex、smoker 自動拆成 5 欄）；有缺值的病人：補上缺值後使用；前處理 1 個步驟（One-Hot 編碼：sex、smoker）」。下方的「前處理步驟」大多數人不需要，自己加步驟收在「進階」。

已經有結構定義檔（JSON）的進階使用者，可在上傳表單的「進階：自行提供結構定義（JSON）」載入；檔案中有、結構定義沒列出的欄位，上傳前會詢問要自動加入或捨棄。

### 資料準備須知

平台能自動處理的不需要事先整理：欄名可以用中文、空白與符號；空白、`NA`、`N/A`、`-` 等自動視為缺值；Excel 另存的 CSV（UTF-8 或 Big5）都可以；不必把文字改成數字代碼。只需要注意：

1. 一列一位病人（或一次就診），第一列是欄名，欄名不可空白或重複。
2. 同一欄只放一種內容，單位一致（例如體重都用公斤）；日期寫成 `2024-01-31`。
3. 移除姓名、身分證字號等可直接識別個人的欄位；病歷號可保留，但不要當 Feature。
4. 要預測的結果（Target）放在同一欄，例如是否診斷為 0／1。

## 段落 4：建立訓練、匯出模型、部署與推論

以計畫主持人（Principal Investigator，有 Training 與 Coding 權限）登入。

1. 「數據管理」→「結構式資料」→ 點資料集名稱（例如 `lung-clinical`）→ 按「用這份資料建立訓練」。「建模管理」會開好新增表單：已選好資料集，帶入資料集設定過的 Target、Feature、缺值處理與前處理（訊息寫出幾個欄位、怎麼拆、缺值怎麼處理），並依目標欄位預選「結構式分類」（類別或 0／1）或「結構式迴歸」（連續數字）。
2. 確認或選擇「要預測的結果（Target）」與「用來預測的資料（Feature）」。資料集已轉成 One-Hot 的欄位只顯示一項，例如「sex（已轉成 sex_F、sex_M）」，已勾選、不用再勾；文字或類別欄位（例如性別、吸菸）不用先處理，訓練時會自動轉成 0／1 欄位。選到有缺值的 Feature 時，同樣可選「補上缺值」或「不使用這些病人」。
3. 驗證方式：資料少於 1,000 列時平台已預選「K 折交叉驗證」（K 用 5），並寫出原因；資料很多時用「固定比例切分」。自己改過的選擇與已存的設定不會被改掉。每個超參數旁都有白話說明與建議值，不確定就保留預設值；不常調的收在「進階設定」。亂數種子決定資料怎麼隨機分組，同一個號碼重跑結果完全相同，一般不用改。按「儲存設定」。
4. 在訓練設定清單按「送出訓練」。送出前平台會先檢查設定與資料是否一致（例如資料集的 Target／Feature 改過、勾了病歷號這類每列都不同的欄位），有問題會直接說明，不會排隊後才失敗。訓練設定和資料集目前的設定真的不同時，旁邊會出現「與資料集設定不同」並用一句話說出差在哪裡（例如「Feature 多了 glucose」），按「套用資料集設定」即可。
5. 「訓練紀錄」的步驟條會自動更新：已送出 → 排隊中 → 訓練中 → 完成（或失敗）；頂端「已送出訓練」的訊息也跟著改成「訓練中」「已完成」或「失敗」。失敗時只顯示中文原因與「前往修正」連結，程式訊息收在「技術細節」。
6. 完成後看「模型好不好？」：最上方一句結論，例如「整體表現：良好（AUC 0.84，5 折平均）」。數字的規則固定：有 K 折用 K 折平均，否則用測試集；分類看 AUC（0.9 優秀、0.8 良好、0.7 尚可），迴歸看 R²。訓練清單的「主要分數」是同一句話。下面寫出用了哪些病人（例如「共 100 位病人，訓練 80 位、測試 20 位。有 5 位的缺值已用訓練資料的中位數或最常見的值補上」），重點指標卡（與結論同一個來源，每個有一句白話與怎麼看才算好），一句比較基準（「每個人都猜「0」可猜對 60%；模型要明顯高於它才有用」）。結論下方就有「用這個模型預測病人」與「分享給同事使用」。測試集的數字、提醒（例如測試人數少、模型可能只記住了訓練資料，建議依演算法給：隨機森林調小最大深度、邏輯斯迴歸調小 C 或減少欄位、梯度提升調低學習率）與 K 折各折收在「詳細」，需要時再展開。圖表有混淆矩陣、ROC 曲線、特徵重要性（迴歸為預測值對實際值與殘差分布）。按「下載報表（可列印）」得到一頁 HTML（同一句結論，分享過的模型以顯示名稱為標題），可用瀏覽器列印成 PDF。訓練清單可按「主要分數」排序，預設只列自己送出的。
7. 「模型匯出」：「下載模型（PKL）」（影像為 H5），畫面顯示檔名與 SHA-256；「匯出原始碼」下載範本＋這次設定的 zip（需要 Coding 權限）。
8. 按「分享給同事使用」：「AI 模型部署」頁已選好這個模型，顯示名稱預設為訓練設定名稱（可改成中文，例如「心臟科確診預測」），填同事帳號（例如 md01）後按「分享給同事使用」。成功訊息、模型清單、推論服務管理都用這個顯示名稱，模型名稱以小字附在後面（同一個模型分享多次時，看分享給自己的最新一次，否則看最新一次）。「已分享的模型」可「修改分享對象」或「停止分享」。資訊人員要用程式呼叫時，展開「給資訊人員：程式呼叫方式」看端點 `POST /api/inference/<技術名稱>/predict`（技術名稱由平台自動產生）、呼叫範例與 Token 說明。
9. 「試用預測」：填一位病人的資料，按「預測」，結果寫成「diagnosis＝1 的機率 83%（模型預測為「1」）」。二元分類的機率一律是陽性類別（0／1 時是「1」，也就是 ROC 與敏感度用的那一類）的機率，不是「預測類別的機率」，所以預測為「0」時也寫 diagnosis＝1 的機率（例如 6%）。補缺值的模型可以留白，結果會寫出補了什麼。預測紀錄記成「單人試用」。
10. 回到「建模管理」的結果按「用這個模型預測病人」：「推論服務管理」（副標題「用模型預測病人」）已選好模型。「一位病人」填表預測；「多位病人一起預測」（也叫批次預測）選資料範圍（例如測試資料）或上傳 CSV。結果上方有一句摘要；資料裡有實際結果（例如測試資料的 diagnosis）時，多一欄「預測對／錯」與一行「20 位中預測對 14 位（70%）」。畫面上的欄名是中文（預測結果、「diagnosis＝1 的機率」、說明）；下載的 CSV 保留英文欄名：prediction、prediction_probability（預測類別的機率，意義不變）、prediction_note，另有 prediction_positive_probability（diagnosis＝1 的機率），並保留實際值欄。同事 md01（醫師，有推論權限）登入後在這裡看到分享給他的模型並可預測。影像模型可上傳影像或選資料集中的一群影像一起預測。

影像訓練（影像分類、分割、物件偵測）在「建模管理」按「新增訓練設定」，選訓練種類、標註來源、Label、Resize 與資料增強。「建模管理」下方的「專案工作」可查看訓練在 GPU 佇列的排隊與執行狀態。
