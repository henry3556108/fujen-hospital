# 教育訓練示範流程（D-02）

示範以無程式碼的網頁操作為主。每一段都有對應的 Playwright 腳本（`platform/web/e2e/demo-flow.spec.ts`），確保教材寫的步驟實際做得到（TC-D02-03：示範無法重現 0）。

| 段落 | 內容 | 狀態 |
|---|---|---|
| 1 | Admin 建立專案、指派成員與角色；成員登入後只看到有權限的入口 | 可示範，腳本通過（Chromium、Edge） |
| 2 | 上傳影像與 CSV、篩選、檢視統計 | 可示範，腳本通過（Chromium、Edge） |
| 3 | 影像標註、自動標註、修改後儲存 | 可示範，腳本通過（Chromium、Edge） |
| 4 | 建立訓練、匯出模型、部署與推論 | 可示範，腳本通過（Chromium、Edge）：在「建模管理」建立訓練設定並送出訓練、下載模型與匯出原始碼，在「AI 模型部署」部署並授權帳號，在「推論服務管理」推論 |
| 5 | FHIR 資料來源、對應規則、排程 | 可示範，腳本通過（Chromium、Edge） |
| 6 | LLM Playground、知識庫、發布 API | 可示範，腳本通過（Chromium、Edge） |

各段落從首頁開始、只點頁面上的連結與按鈕，彼此不依賴。

## 段落 4：建立訓練、匯出模型、部署與推論

以 Principal Investigator（有 Training 與 Coding 權限）登入。

1. 「建模管理」→「新增訓練設定」：輸入設定名稱，訓練種類選「影像分類（H5）」，標註來源選「影像標註平台」，填 Label（例如 `CT, MR`）、Resize、亂數種子，視需要設定資料增強（旋轉、長寬位移、Shear、Zoom、水平與垂直翻轉），按「儲存設定」。影像範圍可選「全部研究」或勾選指定研究；結構式訓練改選資料集、Target、Feature 與演算法。
2. 在訓練設定清單按「送出訓練」。「訓練紀錄」的狀態會自動更新：排隊中 → 執行中 → 已完成（失敗時顯示原因）。完成後可看指標，按「檢視訓練輸出」看訓練紀錄。
3. 在該筆訓練的「模型匯出」按「下載模型（H5）」（結構式為 PKL），畫面顯示檔名與 SHA-256；按「匯出原始碼」下載範本＋這次設定的 zip（需要 Coding 權限）。
4. 「AI 模型部署」：選剛訓練好的模型，輸入部署名稱（小寫英數字與 `-`）與授權帳號，按「部署」。線上部署清單顯示呼叫端點 `POST /api/inference/<部署名稱>/predict` 與呼叫範例；可「管理授權」修改帳號、「取消部署」停止端點。
5. 「推論服務管理」：選模型，上傳影像或 CSV 推論，檢視結果與歷史、下載結果。

「建模管理」下方的「專案工作」可查看訓練在 GPU 佇列的排隊與執行狀態。

## 執行

```bash
cd platform/web
npx playwright test e2e/demo-flow.spec.ts      # 測試模式（模擬 API），Chromium 與 Edge
```

在真環境示範前，另以 `e2e-real` 的方式對 compose 堆疊跑一次。
