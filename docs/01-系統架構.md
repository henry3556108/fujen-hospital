# 系統架構分層

| 層 | 說明 | 模組 |
|---|---|---|
| 使用者 | Chrome、Edge | Admin、User；角色：Viewer、Coder Assistant、Research Assistant、Medical Doctor、Principal Investigator |
| 入口與權限 | 所有功能從這裡進 | A-02 核心入口與網頁操作介面<br>A-03 帳號、角色與權限管理 |
| 資料層 | 資料進來、整理、看懂 | B-01 數據管理與醫療影像匯入<br>B-04 結構式資料與醫學統計 |
| 標註層 | 讓資料有答案 | B-02 影像標註平台<br>B-03 自動標註整合 |
| 模型層 | 訓練、部署、推論 | B-05 自動訓練與模型匯出<br>B-06 模型部署與推論服務 |
| 生成式 AI | 本地開源 LLM | B-07 大型語言模型與 RAG<br>B-08 LangGraph 工作流與 Wiki 知識庫 |
| 醫療資料交換 | 標準化互通 | C-03 HL7 FHIR 醫療資料交換平台 |
| 算力與監控 | GPU 怎麼分、系統健不健康 | C-01 多台 GPU／CPU 伺服器管理<br>C-02 系統監控工具 |
| 基礎環境 | 甲方主機之上 | A-01 平台環境與底層庫建置 |
| 貫穿全平台 | 治理與交付 | D-01 軟體來源與資安合規<br>D-02 教育訓練與交付文件 |
