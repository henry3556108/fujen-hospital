## TC-A02-05 GPU 獨占模式

**合約指標**：「以獨占單一 GPU 執行建模訓練 1 次……工作建立成功率 100%，工作狀態（等待、執行中、完成或失敗）流轉正確率 100%；工作本身之運算耗時不列入本項」。

**前置條件**：
- P1-lung-ct 綁定 GPU 群組 gpu-exclusive（「帳號管理 › 專案」列表 GPU 群組欄顯示 `gpu-exclusive`）。
- 「帳號管理 › 共享排程設定 › GPU Dashboard」上 gpu-exclusive 至少 1 張卡顯示「閒置」或只有別人的 1 件工作（共用環境裡其他人可能正在用，見[截圖](shots/TC-A02-05/GPU-Dashboard.jpg)）。

**使用資料**：pi01（或 ra01，需有 Training 權限）；admin01 看 GPU Dashboard。

**操作步驟**：

1. 視窗 A 以 admin01 登入，點左側「帳號管理」→ 分頁「共享排程設定」→ 分頁「GPU Dashboard」。頁面每 5 秒自動更新。截圖。
2. 視窗 B 以 pi01 登入，確認「目前專案」是 P1-lung-ct。
3. 視窗 B 點左側「建模管理」，在「排程」區點「專案工作」。
4. 在「送出工作」表單：「工作種類」選「訓練（GPU）」，「執行秒數（1-3600）」輸入 `60`，「記憶體（MB，1-256）」保留 `16`，「讓這件工作以失敗結束」不要勾。

## TC-A02-07 共享排程設定頁

**合約指標**：「共享排程設定於網頁介面配置 3 次，設定儲存後重新載入與設定值一致率 100%」。
