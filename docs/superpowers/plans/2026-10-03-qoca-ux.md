# 結構式資料與訓練操作改善（參考 QOCA AIM）

**來源：** 成大醫院臨床創新研發中心《QOCA® AIM 操作簡易說明 ver. 2.2》（數值型資料機器學習分析平台）。
**目標使用者：** 醫院內的醫師、護理與研究人員，不寫程式、不熟機器學習術語。
**原則：** 學 QOCA「一條路走到底、每步一個決定、結果用圖呈現」；不學它把資料整理丟給使用者（英文欄名、手動 NA、手動重新編碼）、英文術語、讓使用者選佇列。

## 比對結論

| 步驟 | QOCA AIM | 我們（改善前） | 改善方向 |
|---|---|---|---|
| 上傳 | CSV + 簡單表單 | 必須提供 JSON 結構定義 | 自動推斷欄位型態，畫面上確認；JSON 改為進階選項 |
| 欄位確認 | 一個視窗列出每欄型態、缺值數，並選 Target／Feature | Target 與 Feature 分頁只有欄名勾選 | 欄位總覽：型態、缺值、唯一值、提示；可把數字編碼的欄位標成類別 |
| 資料到訓練 | 4 步驟精靈 | 數據管理與建模管理兩段，Target 要重選 | 「用這份資料建立訓練」帶入設定 |
| 超參數 | 欄位旁有說明圖示 | 只有參數名稱 | 白話說明、預設值、進階收合 |
| 驗證方式 | K 折交叉驗證 | 只有固定比例切分 | 新增 K 折 |
| 進度 | 圖示步驟條（但需手動重新整理） | 文字狀態，自動更新 | 圖示步驟條＋保留自動更新 |
| 結果 | 混淆矩陣、ROC、特徵重要性、報表 | 指標數字表 | 圖表與可下載報表；清單可依分數排序 |
| 部署 | 結果列上的部署按鈕 | 另一頁 | 「部署此模型」捷徑 |

## 工作分組

### A. 數據管理端（M1：B-04，10/22 驗收前完成）— 分支 `ux-tabular-data`

A1. **上傳免寫 JSON**
- 新 API `POST /api/projects/{pid}/tabular/schema/infer`（multipart CSV）：回傳推斷的結構定義與每欄摘要（型態、缺值數、範例值），並附「依此結構驗證」的預檢結果（通過幾列、拒絕幾列與原因），不寫入資料。
- 推斷規則：以多數值決定型態（例如 95% 以上可轉成數字即為數字），少數無法轉換的格子在驗證時被拒絕並列出原因，維持 TC-B01-10「錯誤攔截 100%、誤放行 0」。
- 缺值辨識：空白、`NA`、`N/A`、`null`、`NaN`、`-` 等視為缺值（可設定）。
- 允許中文欄名與空白、符號（顯示與存放都保留原名）；若有欄名限制，在畫面上說明並提供自動改名。
- 網頁：選檔後自動推斷，顯示可編輯的欄位表（欄名、型態下拉選單以中文顯示：整數、小數、類別、文字、日期、是否；必填；選填的最小與最大值），按「上傳並驗證」使用畫面上的結構。原本的 JSON 欄位與載入結構檔收在「進階」。

A2. **欄位總覽（Target 與 Feature 分頁）**
- 一張表：欄名、型態、缺值數、唯一值數、Target 單選、Feature 勾選。
- 提示：Target 有缺值；Feature 缺值比例高；疑似識別碼（唯一值等於列數，如病歷號）建議不要當 Feature；Target 類別只有一種。
- 「當作類別」切換：數字編碼的類別欄（如 0、1、2）可標成類別，儲存時自動加入 One-Hot 前處理步驟（沿用既有 steps）。

A3. 教材與示範：`docs/delivery/教育訓練示範流程.md` 第 2 段改成新流程，加一小節「資料準備須知」（盡量短，平台能自動處理的就不要求使用者）；`e2e/demo-flow.spec.ts` 與 `e2e/tabular.spec.ts` 跟著更新。

### B. 建模端（M2：B-05、B-06）— 分支 `ux-training`

B1. 資料集頁加「用這份資料建立訓練」：開啟建模管理的新增表單，帶入資料集、Target、Feature、前處理步驟，並依 Target 型態預選分類或迴歸。
B2. 超參數白話說明：每個超參數有中文說明與建議值；不常調的收在「進階設定」。
B3. K 折交叉驗證：結構式訓練可選「固定比例切分」或「K 折交叉驗證」（K 預設 5），指標呈現平均與標準差；同一設定與種子結果相同（TC-B05-04 不變）。
B4. 結果圖表與報表：範本另外輸出混淆矩陣、ROC 曲線（二元分類）、特徵重要性（permutation importance，與演算法無關）、迴歸的預測值對實際值與殘差；網頁以既有圖表元件呈現；「下載報表」產出可列印的 HTML。訓練紀錄清單可依主要分數排序，點開展開細節。
B5. 圖示步驟條：已送出、排隊中、訓練中、完成或失敗，保留自動更新。
B6. 完成的訓練上加「部署此模型」捷徑，帶入 AI 模型部署頁。
B7. 匯出的 pkl 仍只依賴 scikit-learn（TC-B05-06），新增的圖表資料不得進入模型檔。

### C. 零脈絡使用者模擬

以不讀程式碼、不知道專案背景的子代理人扮演醫院人員，只透過網頁操作完成同一組任務，回報卡住的地方、看不懂的用詞與所花步驟數。
改善前跑一次作為基準，A、B 合併後再跑一次比較。任務與評分方式固定，兩次一致。

## 不做

- AutoML（見 `2026-10-03-automl-evaluation.md`，之後再評估）。
- 讓使用者選擇運算佇列、在介面提供 Jupyter。
