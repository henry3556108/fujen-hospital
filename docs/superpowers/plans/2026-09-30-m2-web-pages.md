# M2 網頁：建模管理、模型匯出、AI 模型部署 Implementation Plan

> **For agentic workers:** 依 superpowers:test-driven-development 逐 Task 執行；每個 Task 一個 commit。

**Goal:** WP5b 的訓練、匯出、部署 API 已完成，但「建模管理」與「AI 模型部署」仍是骨架頁（「此功能將於 M2 提供」）。本計畫把兩頁做成真的頁面，使用者不寫程式就能：建立與修改 5 種訓練設定 → 送出訓練並看狀態（排隊中、執行中、完成、失敗）與指標 → 下載模型檔（pkl／H5）、匯出原始碼 → 線上部署、管理授權帳號、看呼叫端點、取消部署。教育訓練示範流程段落 4 改為在網頁上實際操作。

**Architecture:**

- 只改網頁（`platform/web`），不改 API。API 缺的東西記在「結果」與交付報告。
- 新增 `src/pages/training/`（建模管理、模型匯出）與 `src/pages/deployment/`（AI 模型部署）。API 呼叫集中在 `src/pages/training/api.ts`，沿用 `api/client.ts` 的 `ApiClient`；檔案下載照推論頁的做法以 fetch 取 blob。
- 模擬 API 放在 `src/mocks/training.ts`：訓練設定（照 `app/training/config.py` 正規化與驗證）、訓練（每次查詢往前推一個狀態）、原始碼匯出、模型下載、部署。狀態用 `moduleState`，瀏覽器重新載入後仍在（測 TC-B05-02）。
- 共用檔只加最少行數：`App.tsx`（2 條路由）、`entries.ts`（2 個 `placeholder: false`）、`mocks/handlers.ts`（掛上訓練模擬，放在標註模擬之前）。

## 頁面與 API

前綴 `/api/projects/{pid}`。

| 頁面／區塊 | 呼叫的 API | 權限 |
|---|---|---|
| 建模管理：訓練設定清單、新增、修改、刪除 | GET `/training/catalogue`；GET／POST `/training/settings`；GET／PUT／DELETE `/training/settings/{sid}` | training |
| 建模管理：資料來源選項 | GET `/imaging/studies`（影像範圍）；GET `/tabular/datasets`、`/tabular/datasets/{id}`、`/tabular/datasets/{id}/target-feature`（結構式） | project |
| 建模管理：送出訓練、訓練清單、狀態、指標、取消、訓練輸出 | POST `/training/settings/{sid}/runs`；GET `/training/runs`、`/training/runs/{rid}`；POST `/training/runs/{rid}/cancel`；GET `/training/runs/{rid}/log` | training |
| 建模管理：模型匯出 | GET `/models/{mid}/download`（training）；GET `/training/runs/{rid}/source`（coding） | training／coding |
| AI 模型部署：模型清單 | GET `/models` | prediction（入口規則） |
| AI 模型部署：下載模型、部署、授權帳號、取消部署 | GET `/models/{mid}/download`；GET／POST `/deployments`；PUT `/deployments/{did}/access`；DELETE `/deployments/{did}` | training |

沒有權限時沿用既有樣式：入口被擋用 `AccessDenied`；頁內缺某一權限（例如沒有 Coding 不能匯出原始碼、沒有 Training 不能部署）用 `Alert tone="info"` 說明並隱藏操作。

## Tasks

1. 本計畫。
2. 訓練 API 用戶端與模擬 API（`pages/training/api.ts`、`mocks/training.ts`、`mocks/handlers.ts`）；標註頁「建立訓練任務」改由同一個訓練模擬處理，移除 `mocks/labeling.ts` 內重複的兩個訓練端點。
3. 建模管理：訓練設定表單（5 種、影像範圍、Label、Resize、切分、亂數種子、6 項資料增強、超參數；結構式資料集、Target、Feature、演算法）與清單，存檔後重新載入一致；送出訓練、狀態（排隊中→執行中→完成／失敗，進行中自動更新）、指標、取消、重跑、訓練輸出。`entries.ts` 的建模管理改為實際頁面、`App.tsx` 加路由。
4. 模型匯出：完成的訓練下載模型檔（pkl／H5，顯示 sha256）與匯出原始碼（需 Coding）。
5. AI 模型部署頁：模型清單、下載模型、部署（名稱、授權帳號）、修改授權帳號、呼叫端點、取消部署。`entries.ts` 的 AI 模型部署改為實際頁面、`App.tsx` 加路由。
6. Playwright：建模管理與部署的流程；`demo-flow.spec.ts` 段落 4 改成在建模管理建立訓練、匯出模型、部署；教材段落 4 同步。
